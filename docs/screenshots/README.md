# Feature captures

Generated by `pnpm screenshots` using the production Waveflow renderer, UI and embedded font. The same deterministic demo audio is used for every style so comparisons are repeatable. These previews do not contain an account, private playlist or external album artwork.

The macOS packaging workflow regenerates these images from the source commit it builds. Run `node scripts/capture-features.mjs --preview-only` to inspect the same fixture locally without launching an automated browser.
